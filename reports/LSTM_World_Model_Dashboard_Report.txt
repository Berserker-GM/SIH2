1. PURPOSE
----------
Put the frozen world-model answers on the existing SOC dashboard:

  Something bad?   P(attack in 30s) vs threshold 0.15

2. WHAT WAS WIRED
-----------------
New HTTP service (no Redis):

    python -m src.world_model.api          # http://0.0.0.0:8001

  GET  /health
  GET  /api/world-model/status
  GET  /api/world-model/examples
  GET  /api/world-model/forecast?i=N       replay 01 Mar explanation N
  POST /api/world-model/forecast           live 8×32 history (needs LSTM loaded)

Dashboard:

  frontend/src/components/WorldModelPanel.jsx
  mounted in UnifiedDashboard center column (under the ticker)

  Vite proxy: /api/world-model → :8001  (other /api still → :8000)

docker-compose: world_model service on port 8001.


3. HOW TO RUN THE DEMO
----------------------
Terminal A (repo root Normnative-/):
  python -m src.world_model.api

  npm install --legacy-peer-deps
  npm run dev

Open http://localhost:3000/
Panel: WORLD MODEL · 30s FORECAST
