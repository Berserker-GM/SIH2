## Quick start

### 1. Install dependencies
```bash
pip install torch scikit-learn redis fastapi uvicorn pandas numpy jsonschema
```

### 2. Train models  (skip if .pt/.pkl already exist)
```bash
python train/train_lstm.py    --csv /data/cicids2018.csv --epochs 30
python train/train_iforest.py --csv /data/cicids2018.csv
```

### 3. Validate
```bash
python validate.py
# Expected: all scores in [0.0, 1.0], ✅ at the end

# Also validate a JSON file against any contract schema:
python schema_validator.py anomaly_score ../contracts/examples.json
```

### 4. Run the scorer service
```bash
python anomaly_scorer.py
```

### 5. Expose /api/metrics
```python
from fastapi import FastAPI
from metrics_service import router as metrics_router
app = FastAPI()
app.include_router(metrics_router)
```

## Integration Contracts

### Redis channels
| Channel          | Direction        | Schema                      |
|------------------|------------------|-----------------------------|
| `features:ml`    | SUBSCRIBE (read) | `ml_feature_vector.schema.json` |
| `scores:anomaly` | LPUSH + PUBLISH  | `anomaly_score_object.schema.json` |
| `events:normalized` | SUBSCRIBE (optional) | `normalized_event_object.schema.json` |

### FEATURE_ORDER — sync with Dev 1 before Day 2

**LSTM (11 features — `lstm_autoencoder.py`):**
```
login_fail_count, login_success_count, unique_dest_ips,
bytes_sent_total, file_ops_count, cpu_pct_avg,
payload_flag_count, inter_arrival_ms_avg, entropy_dest_ports,
src_port (pre-normalised), dest_port (pre-normalised)
```

**IForest (9 features — `isolation_forest.py`, excludes port fields):**
```
login_fail_count, login_success_count, unique_dest_ips,
bytes_sent_total, file_ops_count, cpu_pct_avg,
payload_flag_count, inter_arrival_ms_avg, entropy_dest_ports
```
